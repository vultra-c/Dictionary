# 离线词典技术设计

运行时采用 Vela UX 单页面和纯 JS 查询引擎，具体数据结构见 `.monkeycode/docs/ARCHITECTURE.md`。词库由 Python 在 Actions 内生成，字典内容和索引作为应用静态资源进入 RPK。

接口：`createDictionary(readText)` 返回 `search(query, offset, limit)`、`get(id)`、`candidates(pinyin)` 三个 Promise 接口。读取错误向页面传播；页面提供重试并使用请求代次过滤过期结果。普通 ID 为数字，缺少独立词条的变化形式使用字符串 ID。

约束：每片最多 32,768 字节；详情页每片 24 词；LRU 最多 4 文件；结果与关系每页 12 条；英文输入防抖 160ms。中文释义保留前 240 字符以约束展示与数据体积，中文反查范围为该保留释义。音标沿用源数据。

验证：纯逻辑测试覆盖前缀、中文子串、双向关系、分页、异常与缓存；页面测试覆盖输入防抖、中文连续选字、旧响应、返回与销毁。CI 检查固定来源哈希、生成规模、包名、签名块及 7,000,000 字节上限。真机验收负责字体、布局、触控和峰值内存。
