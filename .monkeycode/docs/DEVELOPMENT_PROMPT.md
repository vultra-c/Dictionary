# 后续开发提示词

你正在维护小米手环 9 Pro 的 Vela 离线词典。先阅读 README、ARCHITECTURE 和源代码，再执行修改。

必须保持以下验收条件：

1. 分辨率 336×480，黑底、蓝色操作、可触控大字号。遵守 Vela 单 class 选择器、list-item type 同构、唯一 tid，输入区避免被键盘遮挡。
2. 搜索引擎保持纯 JS，系统 API 仅在页面适配。词库按需读取，避免整库 JSON 导入或全量初始化。每个分片最多 32 KB、LRU 最多 4 文件。
3. 保留英文前缀、中文完整释义子串检索、屈折与派生双向导航。派生仅使用有依据的关系，新增关系带来源并补测试。
4. 修改后运行纯单元测试，提交并推送。所有词库生成与 RPK 构建交由 Actions，检查对应提交的 workflow 结论与真实包体积。
5. 保留固定来源哈希和许可证；包体积超过 7,000,000 字节必须使 CI 失败。保持稳定应用包名、签名和升级版本。

关键回归：`ap → apple`、`苹果 → apple`、`went → go`、`action ↔ act`、`readable ↔ read`；空查询、大小写、连续输入过期响应、中文候选分页、读取失败重试、返回顺序、长释义与卸载计时器。

交付说明须区分自动测试、CI 构建与真机验收。完整报告实际词条数、安装包 bytes 和 Actions 链接。凭据使用仓库安全授权与 Secrets。
