# 系统架构

页面通过 `@system.file.readText` 读取包内 `/common/dict/` 资源，将 I/O 适配器传给纯 JS 查询引擎。运行时无需 NLP、SQLite 或网络库。

CI 生成器从固定版本 ECDICT 读取中文、音标和 exchange，读取 WordNet `+` 派生指针，建立双向关系。选词优先级为 Oxford、考试标签、语料词频；补入相关词后仍受最大词条数约束。屈折形式缺少独立词条时，使用虚拟 ID 连接原词释义。

数据层包含 24 词/页详情分片、英文索引目录和叶片、汉字哈希 posting、单字拼音候选，目标覆盖至少 50,000 条。每个 JSON 限制 32 KB，查询引擎最多缓存 4 文件。中文先取首个汉字 posting，再核验完整查询子串；英文先匹配前缀索引。分页通过 offset 和 limit 控制。

UI 采用输入防抖与请求代次标记，避免迟到响应覆盖新输入。详情关系和搜索结果每页最多 12 条。读取失败显示可重试状态；销毁时清除计时器、使异步结果失效。

边界：限定词库覆盖；中文候选采用单字拼音；中文 posting 在高频单字下仍可能需要读取较多详情。最终性能、字体覆盖和系统内存限制需要设备测量。
